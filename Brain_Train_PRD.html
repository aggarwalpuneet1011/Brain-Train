Brain Train 🚂

Master Product Requirements Document (PRD)

Tagline: All Aboard for Olympiad Success!

Vision

Brain Train is a premium Android Olympiad preparation app for an advanced Grade 2 student in India. Claude Code is the development agent. Google Gemini is the only runtime AI provider.

Core Architecture

Offline Guarantee (Mandatory)

Once the quiz package has been downloaded, the device may be placed into Airplane Mode and the entire quiz experience must continue to work without any further network access, including: - Answer validation - Scoring - Lifelines - Explanations - Review Mode - Hall of Fame updates - Daily Streak updates - Mistake Bucket updates - WhatsApp sharing

Technology

  • React Native (Expo)
  • TypeScript
  • NativeWind
  • Zustand
  • Storage abstraction
  • Portrait-only Android

Runtime AI

  • User enters Gemini API Key.
  • User enters Gemini Model (default: gemini-3.5-flash).
  • Never hardcode secrets.
  • Model name must be configurable in Settings.

User Experience & Visual Design (Highest Priority)

This application is intended for a young child and must feel joyful, magical, and premium rather than corporate.

Claude Code should fully leverage its UI/UX design strengths to produce an exceptional mobile experience. Do not generate a generic CRUD interface or basic Material Design screens. Instead, create a polished, delightful experience with thoughtful visual hierarchy, playful interactions, and production-quality craftsmanship.

Design Principles

  • Mobile-first, portrait-only.
  • Every screen should fit without vertical scrolling whenever practical.
  • Soft pastel palette (lavender, mint, sky blue, warm cream).
  • Rounded cards and generous whitespace.
  • Large touch targets (minimum 52dp).
  • Smooth spring animations and subtle micro-interactions.
  • Friendly illustrations, icons, and tasteful SVG animations.
  • Child-friendly typography with excellent readability.
  • Consistent visual language throughout the app.

Emotional Experience

The app should feel like boarding a magical learning train. Every interaction should reinforce the Brain Train theme with encouraging language, delightful transitions, and positive reinforcement. The experience should inspire curiosity rather than test anxiety.

Gemini API Strategy

Maximum Network Calls

The application should make at most two Gemini API calls during a user session.

Call 1 (Optional): Session Initialization Used only if dynamic coaching content is required before quiz generation.

May include: - Greeting - Streak acknowledgement - Leaderboard recognition

Call 2 (Mandatory): Quiz Session Package

Exactly one request generates the complete quiz package.

The prompt includes: - Student name - Subject - Difficulty - Current streak - Best score - Hall of Fame summary - Mistake Bucket summary - Weak topics

The response must contain everything required to complete the quiz offline.

  "questions":[
    {
      "id":"SCI-001",
      "question":"",
      "options":["","","",""],
      "correct_index":0,
      "explanation":"",
      "concept":""
    }
  ],
  "answer_key":[0,2,1],
  "backup_question":{
    "id":"",
    "question":"",
    "options":["","","",""],
    "correct_index":0,
    "explanation":"",

}

Validation

  • Validate JSON.
  • Retry once if invalid.
  • Attempt repair.
  • Reject inconsistent payloads (e.g. correct_index does not match answer_key).
  • Never crash.

Gameplay

  • One question per screen
  • 50-50 once
  • Flip Question once (uses backup question)
  • No network after package download
