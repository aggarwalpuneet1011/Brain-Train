Brain Train 🚂

Master Product Requirements Document (PRD)

Tagline: All Aboard for Olympiad Success!

1. Vision & Core Philosophy

Brain Train is a premium Android Olympiad preparation app built specifically for an advanced Grade 2 student in India. The application moves completely away from dry, test-based stress, re-imagining competitive exam practice as a magical, progressive train journey. Claude Code serves as the autonomous development agent, and Google Gemini is the exclusive runtime AI provider.

2. Core Technical Architecture

Offline-First Guarantee (Strict Compliance)

To optimize performance and minimize network instability, the application must execute exactly one Gemini API call per active quiz session at the absolute beginning. Once the complete quiz package payload is downloaded, the application must be capable of running entirely in Airplane Mode. The following features must process natively and completely offline:

  • Answer validation, scoring tracking, and active index shifting.
  • KBC-style lifeline computations (50-50 mask logic and backup question swapping).
  • Review Mode generation, color code shifting, and explanation rendering.
  • Local storage updates (Daily Streaks, Leaderboard additions, and Mistake Bucket parsing).
  • Native app-to-app WhatsApp deep-linking generation.

Technology Stack

  • Framework: React Native (Expo Workflow) managed via TypeScript.
  • UI Styling: NativeWind (Tailwind CSS configuration for React Native).
  • State Engine: Zustand (Lightweight local client-side state machine).
  • Screen Locking: Hard-locked strictly to Portrait Mode across all activities.
  • Storage Abstraction: Secure local JSON caching managed entirely via client storage abstractions (AsyncStorage/MMKV).

Runtime AI Engine Settings

  • The app utilizes a secure initialization screen where the user inputs their personal Gemini API Key.
  • The key must be written instantly to secure client storage and never hardcoded, logged, or sent to any external server except directly to the official Google Gemini endpoint.
  • Model Constraint: Hardwire all operations exclusively to the gemini-3.5-flash model payload endpoint to capture ultra-low latency generation cycles. Provide a configuration field inside settings to easily swap model pointers later.

3. Branding & Interactive UX Framework

Claude Code must leverage its peak frontend capabilities to build a fluid, child-first interaction canvas. Avoid standard rectangular buttons or bland dark modes. Deploy a layout utilizing soft pastel palettes (soothing lavender, fresh mint, soft sky blue, warm cream backdrops) paired with micro-interactions (bouncy scale-up triggers on selection, subtle shadows shifting to inner deep-shadow cards upon tap).

The Train Journey Metaphor Mapping

  • Subject Matrix Panel: "Choose Your Destination" Selection Grid

4. Startup Onboarding & Main Dashboard

Gateway Collection Fields

On initial launch, prompt the user for the following persistent parameters:

  • Gemini Key Field: Secure input masking box (saved permanently to client localStorage cache).
  • Student Identifier: "What is your name?" (Saves text state to inject personalized callouts across screens).
  • Difficulty Level Selection: A prominent segmented slider allowing a toggle between:
    • Challenger: Standard competitive Grade 2 Indian Olympiad criteria.
    • Mastermind: Extreme top-of-class, high-achiever mastery tier.

Main Dashboard Components

  • Analytics HUD (Heads-Up Display): Top-pinned persistent metrics displaying:
    • 🔥 Daily Streak Tracker: Computes consecutive days of activity via timestamp validation.
    • 🏆 Engineer’s Log (Hall of Fame): Triggers an overlay presenting the top 5 historic scores, capturing the date stamp, subject type, and the difficulty tier ("Challenger" or "Mastermind").
  • Subject Destination Grid: Large interactive touch cards utilizing distinctive custom vector icons or fluid SVGs:
    • English: Storybook icon (Grammar, Spellings, Antonyms, Synonyms, Homonyms, Animal Kingdom, Nature).
    • Science: Rocket ship or swirling atom icon.
    • General Knowledge: Sparkling lightbulb or Planet Earth icon.
    • Computers: Friendly AI avatar or laptop icon.
    • 🎯 Repair Yard (Mastery Mode): A special card that unlocks only when the local Mistake Bucket array contains failed questions. Selecting this lets the user play an offline subset containing only items previously missed. Questions clear out of the bucket instantly upon a correct offline response.

5. Single-Question Gameplay Architecture

  • Zero Cognitive Overload: Present exactly one question on screen at any single moment.
  • Child-Finger Optimized Targets: Do not render standard web radio circles. Options must appear as large vertical touch blocks (minimum height 52dp) that glow or alter border hues dynamically upon single-select interaction.
  • Backtracking Hub: Provide a clean "Skip Question" trigger coupled with an instantaneous top dropdown menu listing all skipped question markers. Tapping an item immediately returns the user to that question layout.
  • KBC-Style Lifelines Panel: Provide exactly 2 lifeline buttons at the base of the screen, restricted strictly to one activation per 20-question set:
    • 🌓 50-50 (Fifty-Fifty): Offline script mask that instantly targets the choice array, leaves the correct option and one random wrong option visible, and entirely greys out/disables the remaining two options.
    • 🔄 Flip the Question: Discards the active question entirely. The state controller smoothly swaps it out and replaces it with the pre-fetched 21st question array element. The core denominator tracking the score is locked entirely to 20; the replacement question gracefully adopts the running position and index configuration of the flipped item to ensure absolute consistency in results tracking.

6. Single-Call Payload Contract (JSON Schema)

Strict Client Validation Step

Before launching the game state, the client-side parser must execute a validation loop checking if questions[i].correct_index === answer_key[i]. If an anomaly is identified, code logic must trigger a quiet auto-retry once or execute a self-heal repair script before opening the gate to the child.

7. Post-Quiz Processing & Communication Hook

Offline Validation & Score Metrics

  • Notation Constraint: Percentages are forbidden in the interface. All output values must render as "X out of 20" notation to maintain absolute clarity for a Grade 2 student.
  • Visual Rewards: Map scores to physical graphical animations (e.g., 5 gleaming golden stars for a perfect 20 out of 20, dropping down dynamically relative to fractional tier groupings). Display the corresponding pre-fetched tier string from the score_feedback JSON payload block.
  • Review Matrix: Present a post-game review stack. If an answer was wrong, flag the user's selected choice container in sharp Crimson Red, highlight the accurate option container in deep Emerald Green, and render the inline explanation bubble beneath it.

WhatsApp Communications Interface

Provide a native app-to-app deep-linking share button utilizing the whatsapp://send?text=... intent uri template structure. This completely bypasses intermediate web browser tabs, ensuring instant mobile communication mapping. Construct the message parameters explicitly using this structure:

🌟 *Brain Train Update for [Name]!* 🚂
🎯 *Destination:* [Selected Subject]
🏆 *Tier Level:* [Challenger / Mastermind]
📊 *Score:* [X] out of 20
🔥 *Current Daily Streak:* [X] Days Running!

_Sent from my Olympiad Prep App_ 🚀

8. Agentic Deployment Protocols (Claude Code Guidelines)

  1. Autonomous Execution Loop: Initialize a completely local project repository workspace container. Scaffold all essential TypeScript modules, storage abstractions, layout schemas, and animation bindings internally. Debug and verify component performance loops without interrupting the user.
  2. GitHub Commits Hard Gate: Stage and execute orderly, clean commits inside your local Git repository tree. Pause execution and query the user explicitly for permissions and configuration environment tokens only when the foundational structure is 100% sound, verified, and ready to push to remote profiles.
  3. APK Compilation Hard Gate: Prepare all dependency libraries, asset manifest maps, and bundling config files required to generate a native Android container. Stop execution completely before compiling. Present the live, ready application matrix wireframe structure clearly to the user, and wait for explicit manual confirmation before generating the final production-ready APK package file.
